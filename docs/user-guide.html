Alignment grids and outline frames

View > Show Grid (Ctrl+G) overlays matching image-aligned grid lines in both eyes. Grid Settings controls horizontal/vertical line counts from 0 to 100, one or two colors, and opacity. Two-color lines alternate along their length for contrast on textured photographs. Grid position follows the source image as you pan/zoom; the grid also works in anaglyph. It is a workspace aid, hidden in Clean Preview and never exported or stored in the project. Preferences are remembered locally.

Edit Frame > Outline Frame restores the three-band framing idea from the original Stereomasken. First create at least three frame points, then enable Apply outline frame. Offset sets the gap outside the main frame contour in source-image pixels. Inner, Middle and Outer each have a width and color; a zero width omits that band. Use mask color keeps a band synchronized with the current mask color. Bands follow curves and disparity in each eye and remain behind preserved foreground subjects. Existing Picture Frame borders and shadows are independent and may be combined.

Display in editor controls the outline during ordinary editing and Preview Result. Clean Preview and export always show an applied outline. Apply commits one undoable settings change; Cancel leaves settings unchanged. Outline settings persist under pictureFrame/outline in .msk projects; older projects have outlines disabled. Older readers may discard these fields, so exchange project copies. Outlines are clipped to the existing image canvas; they do not add export margins.

Start here

StereoMask works on an existing side-by-side stereo photograph. It does not turn a flat photograph into 3D. Use a Parallel pair (left eye on the left, right eye on the right) as your source. For a Crossview pair, swap its halves in your image editor before importing; the app’s Swap button changes the display only, while export uses left-eye/right-eye order.

There are two parts to an out-of-window edit:

  1. The frame: a shared outline made with dots. Its horizontal offset between the two eyes sets its apparent stereo depth.
  2. The preserved foreground: extra areas selected separately in each eye, using the Polygonal lasso or Select Brush. The frame opening is the starting visible area; ordered Add/Subtract objects then modify it.

Smart polygon lasso follows color and brightness edges between clicked anchors using OpenCV. Place anchors close together around difficult edges; inspect and adjust the outline before applying. Texture, shadows, and low contrast can lead it away from the intended boundary. Trace each eye separately, or enable paired lasso and inspect the estimated opposite-eye copy.

Preview Result is enabled by default. It renders the selected Export background mode using the same per-eye compositing as export, including ordered selections and holes. Match preview uses Mask color and opacity; Black, White and Custom cutout color use solid backgrounds. Transparent PNG uses a non-exported checkerboard in side-by-side view. Turn Preview Result off to see the full source photograph with a green selection overlay while tracing. Toggling preview does not change your selections or exported image. The original photograph is not altered.

Toolbox drawers, History and Guided Process

The narrow icon rail on the left opens File, Quick Access, View, Create Frame, Edit Frame, Out-of-Frame, Help and History drawers. Command drawers are 150 logical pixels wide, with compact inputs and left-aligned borderless buttons. Dropdowns and Open Recent fill the usable drawer width. History uses a compact 240-pixel width for its object list. Hover an icon or compact control to see its full name. Click to open a drawer and click again to close it, reclaiming canvas space. Only one docked drawer opens at a time; long controls scroll within the drawer rather than taking more canvas space.

Drag a drawer title bar to float it or move it to the right. Floating drawers can stay open independently. The open drawer, widths and positions are remembered between sessions in layout.ini. Choose View > Layout > Close all drawers for the largest canvas, or Reset toolbox layout to return to the left-side Create Frame drawer. View also restores a hidden Toolbox rail. The rail Main Menu and the normal menu bar retain the existing actions and shortcuts; Stereo Window, Text & Bubbles and Guided Process have direct rail buttons. Help is last, immediately after Guided Process.

Quick Access keeps your frequently used commands in a 150-pixel drawer, opened with the star icon. Right-click a command button and choose Add to Quick Access. The manager button in Quick Access opens a searchable command list. Add or remove commands, drag the chosen list into order or use its up/down buttons, then Save. Cancel discards manager changes. Right-click a favorite to remove or move it directly. Favorites use the original commands and retain their enabled and checked states. Your list and its order are saved in layout.ini, independently of the current project.

History lists the applied foreground workflow objects in their processing order. It is more than a selection picker: you can show or hide an edit, rename it, reopen polygon points, move a polygon, change Add/Subtract, reorder it, or delete it. Undo and Redo still reverse completed project commands.

Guided Process opens an optional step-by-step panel for creating a basic frame, preserving out-of-frame subjects, reviewing the result and saving/exporting. It works with the current project and does not reset edits. Help → Keyboard Shortcuts shows the effective Windows bindings; choose Edit Shortcuts to reassign supported commands. Fixed drawing gestures remain protected.

First optional step — adjust the Stereo Window

After opening an image and before making frame points or foreground selections, choose Stereo Window. It opens in the same full-resolution side-by-side eye layout as the main window. Enable Anaglyph preview only when a red/cyan inspection view is useful. Scroll to zoom, drag to pan, and use Ctrl + 0 to fit.

Use Push back, Pull forward, the Left/Right keys, slider, or exact pixel box until the scene plane you want at the starting stereo window has the intended depth. In anaglyph mode, aligned red/cyan edges identify the window plane. Reset to original returns the draft value to zero. Cancel makes no change; Apply creates one Undo/Redo operation.

The adjustment recomputes both eyes from the untouched source instead of repeatedly resampling them. Canvas dimensions stay fixed, so transparent strips can appear at the outside edges. Existing frame and selection coordinates do not move; for that reason, make this adjustment before tracing. Saving stores the offset in the project and preview/export use the shifted eyes.

Tutorial 1 — Make a basic stereo frame

  1. Choose New (File → New Project) and open your side-by-side image.
  2. If the source needs a starting depth correction, use Stereo Window now and Apply it before drawing.
  3. Expand Create Frame and choose Create with points, or choose a rectangle, square, oval or circle from Shapes. The Edit Frame section contains point, depth, alignment and transform controls.
  4. In one eye’s image, right-click four corners in order around the opening you want to keep. With a trackpad, use a two-finger secondary click. The frame closes automatically once it has at least three dots; you do not need to click its first dot again.
  5. Left-drag a dot to move it. Right-click away from existing edges to add corners in click order; the outline closes to the first corner. To insert another frame point, remain in Edit frame and right-click within 10 screen pixels of the straight or curved edge that should receive it. Inserting on the closing edge keeps the original first corner. Left-drag empty image space to draw a selection box around several dots. Ctrl-click dots adds or removes them from the group.
  6. Set the depth. Select all four frame dots, then hold Shift and drag a selected dot horizontally. This changes disparity—the separation between corresponding frame positions in the eyes—rather than its ordinary position. Use small adjustments and check the stereo view. Anaglyph can help if you have red/cyan glasses.
  7. For a flat window, use Align → Depth on the selected dots to give them the same disparity. Position it at the scene plane you want—for example, the bench the people are sitting on. Depth is judged from the stereo image; the app does not identify the bench automatically.
  8. Click Save. To export this opening with a transparent or solid outside background, choose Select Brush once to activate cutout editing, choose Export background, then Export.

Auto is an alternative starting frame based on stereo overlap. It works only when no frame points exist and still needs you to check the resulting opening and depth. Freehand creates the initial frame by dragging when no points exist; it is different from painting foreground areas.

Frame shapes, picture frames, shadows and 3D text

Shapes creates an editable rectangle, square, oval or circle at a chosen depth. It replaces the current basic frame as one undoable operation. Right-click within 10 screen pixels of an edge to insert another point; curved edges are split without flattening the curve.

Picture Frame adds a flat, beveled or decorative border behind preserved foreground objects. Its Drop Shadow controls opacity, distance, angle, blur, spread and color, with stereo placement calculated independently for each eye.

Text & Bubbles adds multiple stereo-positioned labels, speech bubbles and thought bubbles. Choose font, size, bold/italic, alignment, fill, outline, opacity, rectangle, tail and depth. Foreground occlusion can let an existing preserved subject pass in front of the text. These objects are saved in the project and included in preview and export.

Emboss, engrave and cutout text

Choose Text effect: Flat, Embossed (raised), or Engraved (recessed). Choose Text surface: Colored letters retains the text color with relief shading; Cutout plate makes transparent letter-shaped openings in a colored plate. Those openings reveal the image underneath, rather than painting letters in a simulated background color. Background / bubble color and Background fill opacity control the plate. With Text only, the plate is rectangular; bubble styles retain their own shape. Relief depth controls the bevel size and raised/recessed letter disparity.

Pitch, yaw and roll

X (top/bottom tilt) is pitch: positive brings the bottom forward, negative brings the top forward. For a lying-on-the-floor pose, try X at +60 to +80 degrees with Y and Z at zero. Y (left/right tilt) is yaw: positive brings the left side forward, negative brings the right side forward. Z (roll) turns the text clockwise for positive values and counterclockwise for negative values; it does not lay the text down.

Both eyes view the same rotated plane, not opposing rotations. X/Y perspective includes a depth gradient across the text while keeping corresponding points vertically aligned. Stereo depth separately moves the whole object forward/back, and relief depth controls the raised/recessed glyph effect. Rotation is centered on the text box; the editing outline and handles follow the eye-specific projection. This is an artistic off-axis stereo projection, not calibrated to your photo's cameras. Applying text is undoable and all settings persist in the project. Relief text remains visible at steep angles; near edge-on text naturally becomes thinner.

Older projects default to Flat, Colored letters and zero tilt. Older applications, including Mac builds without these additions, may ignore or discard relief, surface and tilt fields; exchange project copies.

AutoMask and Freehand starting frames

The Auto dropdown offers QTAGENT Rect Decompose, SGBM Contour and Legacy Smart Mask. These native OpenCV-assisted choices create a starting frame with editable depth points; compare results and adjust manually. AutoMask is available when the frame has no points. The QTAGENT choice is not a guarantee of fully calibrated, independent multi-region occlusion masks.

Freehand also requires an empty frame. Drag an outline; smoothing, simplification and a practical point-count cap produce editable frame points. It is distinct from a foreground lasso or Select Brush. Both frame-creation operations support Undo/Redo. Some calculations use reduced working images/local regions to bound processing; exported photo pixels remain at source resolution. Smart lasso follows contrast, not semantic object identity, and still needs inspection.

Tutorial 2 — Let a leg or object extend outside the window

If your frame already has the right depth, keep it. Work on the extra foreground areas next.

  1. Choose Out-of-Frame → Polygonal lasso and Selection → Add to selection.
  2. Zoom into the object in the first eye with Ctrl + wheel. In frame-point and lasso editing, ordinary wheel scrolling moves both images vertically and Shift + wheel moves them horizontally. Hold the middle mouse button and drag to pan in any direction without switching tools; Space + drag also works.
  3. Left-click along the object’s outline. Use short segments around toes and curved edges. Include only the part that must survive outside the frame, with a small overlap into the frame so the shape connects cleanly.
  4. If a click is wrong, press Delete (or Backspace). It removes the most recent point and segment, keeping the rest. You can also drag the current outline’s points.
  5. Click the first point to close the outline, or press Enter or C, or click Close outline. After closing, its points remain adjustable until applied.
  6. Click Apply selection or press Ctrl+Enter, or click elsewhere to begin the next outline. The previous selection stays, and its boundary remains visible. Repeat for other legs or objects. Overlapping Add shapes enlarge the preserved area.
  7. To trim an unwanted piece, choose Subtract from selection, draw around that piece, close and apply. This covers the selected area, including inside the basic frame opening. Switch back to Add when finished.
  8. Repeat in the other eye, or use the paired-lasso copy. Inspect and adjust that eye’s object edge, because its position differs. A matching subject needs appropriate masks in both eyes to avoid uncomfortable stereo rivalry.
  9. Choose Export background → Match preview to retain mask color/opacity, or Transparent (PNG), Black, White or Custom cutout color for a true cutout. Save the editable project and Export the finished pair. Check it in your stereo viewer.

History objects

The History panel lists applied polygons and raster selections, showing their eye and Add/Subtract operation. Click a row to select its outline. Click its eye icon to hide or show that object in both preview and export. Use Edit points to reopen a polygon, Rename to give it a name, or Delete to remove it. The four-arrow Move polygon toggle translates a selected visible polygon by dragging its interior or edge in its own eye. Shift-drag moves horizontally only; Escape cancels the drag. Movement preserves the whole shape, stays within the image and commits one undo step when released. Raster selections are not moved with the polygon tool. The two-arrow Switch Add/Subtract button changes an object's operation. Undo/Redo restores these operations. Objects apply from top to bottom, starting with the frame opening. Use the up/down arrows to change the order: Add reveals pixels; Subtract covers them, including inside the frame. A later Add can restore part of an earlier Subtract.

Polygon control points, names, operations, visibility and list order are stored in the project JSON. Brush, fuzzy and color-threshold edits are raster objects and do not have editable polygon points. The History button restores the panel if you close it.

Brush and color-selection tools

Select Brush preserves the area you paint; Erase Brush removes extra preservation. Both work separately in each eye. Set Size, or press [ to shrink and ] to enlarge the brush.

Fuzzy Select region chooses only the connected region around the clicked pixel. Select by color threshold chooses matching pixels across the entire clicked eye, including disconnected regions. Set Color tolerance from 0 for exact RGB matches up to 255 for the widest range, choose Add or Subtract, and click a representative source pixel. Each click immediately creates a named History object; repeat with other pixels as necessary. Use Undo if a tolerance was too broad.

What Escape does

While an outline is open, Escape cancels only that unfinished outline. If it is already closed, Escape applies and keeps it. Earlier applied selections remain in both cases. The Cancel unfinished button follows this same rule. After applying a polygon, choose it in the History panel and click Edit points to reopen its control points. Drag points, Shift-click near an edge to insert a new point (including the closing edge), or Ctrl-click a point to remove it and reconnect its neighboring edges. A closed polygon must retain at least three points. Press Enter or C while editing the image to close an open outline, then Apply selection (Ctrl+Enter) to update that same polygon. Undo after applying restores the previous polygon.

Clean Preview

Click Clean Preview on the Mask toolbar, choose View → Clean Preview, or press F8. This shows the selected export appearance, without frame points, polygon outlines, brush cursors or hints. Match preview uses mask color and opacity; solid cutout modes preview their exact solid background. Transparent PNG shows a checkerboard in side-by-side view; the checkerboard is not exported. It also works in anaglyph view. Zoom and pan remain available; turn Clean Preview off to resume drawing.

Unfinished outlines are retained but are not applied automatically. Press Ctrl+Enter to apply a valid lasso, including an open outline with at least three points. Clean Preview does not change your project or export settings, and turning it off restores the previous Preview Result setting and editing marks. Choose Export background → Match preview to export this color/opacity appearance. Transparent and solid-background modes export a cutout instead.

Paired polygon selections

Enable the connected-circles icon beside the Add/Subtract control, then draw a normal or smart polygon in either eye and Apply selection. The app creates two independent objects, one for each eye, using the same operation. OpenCV estimates horizontal alignment from source-resolution patches near the anchors. Ambiguous or textureless anchors use the reliable matches' median shift, or the frame disparity if no matches are reliable.

Inspect the opposite-eye object in the History panel and use Edit points to adjust it. Occlusions, repeated textures, vertical misalignment and large depth changes can prevent accurate matching; the copy is a starting outline, not a guaranteed stereo contour. With smart lasso, copied segments follow edges in the opposite image. Editing either applied polygon never changes or recreates the other. Undo immediately after applying removes both; afterward they can be independently reordered, hidden or deleted. Turn the icon off for one-eye tracing. The toggle starts off when the app opens.

Zoom and pan without changing your work

File opening, selection, AutoMask, edge-refinement, applying text/bubbles, save and export operations show a compact frameless panel with one processing message, also repeated in the status bar. Single-eye selections name the eye being edited; opposite-eye matching is reported only during paired creation. Paired polygon matching, opposite-eye tracing, color matching, selection-mask composition and applied text-layer rendering use workers. Unknown-duration calculations do not show guessed percentages. Editing is temporarily blocked until the operation completes; your zoom and selection remain intact.

Settings

Mask Color and Mask Opacity are the same values shown by the toolbar and used by Match preview. Mask Feathering softens the basic frame boundary only when Preview Feather is enabled for that appearance; it does not feather individual polygons. Horizontal/Vertical Padding add margins; Interleaving Space adds a gap, not an interlaced image. AutoSave saves committed changes; explicitly apply and save before quitting.

Save your project and export your image

Save writes a .msk file alongside the source image. It contains frame settings, picture-frame/shadow settings, stereo text and ordered selection objects: identities, names, physical eye, operation, visibility, anchor coordinates, magnetic flags, paths and raster data. List order is saved. Older flattened masks import as groups; their original polygon anchors cannot be reconstructed. Keep the original image together with it. Close Project clears the current canvas after saving when AutoSave is enabled, or asks whether to save when it is disabled. Export writes a separate masked side-by-side image, normally named with a _masked suffix. Choose a new name to keep earlier exports.

Save and Export apply a closed pending lasso automatically. An open unfinished outline must first be closed or applied. Uncommitted outline clicks are not a substitute for a saved mask.

Choose Match preview to keep the mask color, opacity and faint source background exactly as intended by the overlay. A 95% white mask retains 5% of the original photo outside the opening. For a true cutout, choose Transparent (PNG), Black, White or Custom cutout color; those modes do not use mask opacity. Image viewers may display transparent pixels against black, which is not necessarily a saved black background. Use PNG for transparency. JPEG cannot keep an alpha channel. The exported image does not contain the green selection overlay, dashed outlines or frame dots. Zoom does not reduce its resolution. Lasso contours have antialiased edges; cutout export does not currently provide adjustable feathering of those contours.

Transparent output can be useful in compositing or a viewer that supports alpha. A transparent SBS PNG is still a stereo photograph; this app does not convert it into a VR180 projection.

Check for updates

Choose Help → Check for Updates while connected to the internet. The app checks the version notice in SRathinaGiri/StereoMask on GitHub. You do not need a GitHub account to check this public repository.

If your version is current, the app says you’re up to date. If a newer version exists, it shows the installed and available versions, update notes, and an Open GitHub button. That opens the download page in your browser. Save your project before replacing the app.

Windows releases are downloaded from the repository Releases page. Source code is also available. The checker identifies this clearly; it does not install anything automatically. For a Windows binary release, extract the release ZIP into a folder and run StereoMask.exe. Keep the bundled DLLs and plugin folders beside it. Follow the repository’s current build instructions.

An internet failure or missing update notice is reported as a failed check, not as “up to date.” Try again later, or use Open GitHub to check the repository yourself.

Limits and project exchange

Smart lasso and paired matching are assistance, not guaranteed segmentation. Shadows, textures, repeated patterns, occlusions and vertical stereo misalignment can produce wrong boundaries. Individual selection feathering, selection groups and clicking an applied polygon directly in the canvas to select it are not implemented. Use the History panel to select objects.

Current Windows and Mac builds share the expanded project fields for workflow objects, frame appearance, shadows and stereo text. Keep backup copies when exchanging projects with older releases. Older imported flattened masks retain their appearance but do not regain original polygon vertices.

If something seems wrong

  • Dragging moves the image: Pan is on, or Space/Alt is held. Choose your brush or lasso again and release those keys.
  • You cannot start another polygon: close the current outline, then Apply selection or click away from its points. An open outline must be finished before changing eyes.
  • A closed polygon’s points are gone: it has been applied. The object and its boundary remain. Select it in the History panel and choose Edit points to reopen it; use the panel's Delete to remove the whole object.
  • A subtraction appears filled again: a later Add may restore it. Move the Subtract lower in the History list or hide the later Add. Erase Brush removes painted preservation; use a Subtract polygon to cut inside the frame.
  • An older project has paint but no dashed outlines: older files may contain only the painted alpha mask. Its original polygon points cannot be reconstructed.
  • The export keeps the full picture: make a frame or subtract an area; check that mask opacity is not 0% in Match preview. Choose a cutout mode only if you want a true cutout.
  • The exported background is unexpectedly solid: check Export background. White, Black and Custom cutout color ignore mask opacity. Choose Match preview for the color/opacity blend; preview now honors this same mode.
  • You cannot draw: turn Clean Preview off. It retains unfinished work but hides editing marks and blocks canvas drawing.
  • The copied polygon is misaligned: pairing is an estimate. Select the opposite-eye object, Edit points, adjust and Apply. It is independent of the source object.
  • The app crashes before opening: extract the complete Windows release ZIP and keep all DLLs and plugin folders beside StereoMask.exe.
